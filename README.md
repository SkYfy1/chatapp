## 🤖 Introduction

Built with Next.js, TypeScript, and Postgres, Library Management System platform featuring a public-facing app and an admin interface.


## ⚙️ Tech Stack

- React
- Firebase
- Supabase
- React-Spring
- React-hook-form
- React-toastify
- Zustand
- MUI

## 🔋 Features

### Features of the University Library Management System Project

👉 **Authentication**: Implemented with Firebase Authentication via Email/password.

👉 **Chats**: You can create a conversation with a friend or create a group chat room.

👉 **Profile**: Manage account data, such as: mobile number, user name and account logo. 

👉 **Chat Details**: Check all sended files, images in chat and block or unblock user.  

👉 **Database Management**: Firestore Database from Firebase.  

👉 **Real-time Media Processing**: Supabase for file(such as images, files and audiomessages) uploading/downloading. 

👉 **Zustand**: For simplified and efficient global state management.  

👉 **UI/UX**: Built with MUI.  

👉 **Animation**: React-spring with use-gesture(animations can be disabled in the user menu). 

👉 **Language**: Easy one-button interface language toggle. (UA/EN)
